# NeuralFlow Preview 0.6.0-preview.4

Adds the NeuralFlow flowing-frame icon to the app and installer executables,
application windows, desktop and Start menu shortcuts, and Windows' installed-app
listing. Icon artwork includes nine sizes from 16 to 256 pixels.

Includes the complete offline components from preview.3. Install this update to
refresh shortcuts and the installed-app icon. Personal settings are preserved.

Validated: app startup and Live/Video/System UI checks; Windows icon extraction
from app and installer executables; packaged file hashes and installer payload.
The rendering pipeline is unchanged. This remains an unsigned experimental
Windows 11 x64 NVIDIA-first preview, not native game-integrated DLSS.
